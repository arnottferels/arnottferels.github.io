This conceptual prototype explores a new architectural language based on computational dynamics. It uses fluid, dynamic parallel fins, or “blade-like” elements, that can be adjusted either by human need or intentionally by machines to create surfaces that look fluid, woven, or move with the context or environment.

It moves away from traditional, so-called “static” construction by introducing a system where light, shadow, and perceived movement are the main focus. I named this concept _“Timelessness,”_ which refers to how the material and shape change over time, based on what I described above.

The script will be shared later.
